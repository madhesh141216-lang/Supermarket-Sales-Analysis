# 🛒 Supermarket Sales Analysis & AI Sales Prediction


A data analytics and machine learning project that analyzes supermarket sales, customer behavior, and product performance through an interactive Flask dashboard.


It also predicts the next 7 days of sales using a Gradient Boosting Regressor.


## 🚀 Features


- 📊 Sales & Product Analysis
- 👥 Customer Behavior Analysis
- 📈 Daily & Monthly Sales Trends
- 🏪 Branch & City Filters
- 💡 Automatic Business Insights
- 🤖 AI Sales Prediction
- 🔮 Future 7-Day Sales Forecast
- 📱 Responsive Dashboard


## 🛠️ Technologies


- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Flask
- HTML & CSS


## 🤖 Machine Learning


**Model:** Gradient Boosting Regressor


**Features:**


- Date-based features
- Lag 7 & Lag 14
- Rolling Mean 7, 14 & 30


**Performance:**


```text
MAE: 722.03
R² Score: 0.5157

Run the dashboard:

python app.py
